# Project Two: Predicting MLB World Series Winners

**Research question:** How accurately can an MLB playoff team's regular-season win percentage and performance statistics predict whether it will win the World Series, using data from the 2005–2024 MLB seasons?

This repository contains Nick Hawkins' DTSC 2301 machine-learning portfolio project. It is a binary-classification analysis of 198 MLB playoff team-seasons.

## Start here

- [Published project page](https://dhawki20.github.io/Project2Oct.4/)
- [Jupyter Notebook](notebooks/world_series_prediction.ipynb)
- [Reproducible Python script](analysis.py)
- [Cleaned modeling data](data/mlb_playoff_teams_2005_2024.csv)
- [Model results](data/model_results.csv)

## Reproduce the project

```bash
python -m pip install -r requirements.txt
python analysis.py
```

The script cleans the raw team-season file, engineers rate statistics, fits the baseline and two models, evaluates the 2020–2024 holdout seasons, and regenerates every figure used on the site.

## Data sources

The variables come from the Teams table in Sean Lahman's Baseball Database. The 2005–2014 records were extracted from Donald Ferguson's Lahman CSV snapshot; the 2015–2024 records came from AcroTaken's updated Teams CSV. The repository keeps the exact 600-row combined source file so the analysis remains reproducible.

- [SABR: Lahman Baseball Database](https://sabr.org/lahman-database/)
- [Historical Teams CSV](https://github.com/donald-f-ferguson/W4111F21/blob/main/Examples/LahmansBaseball/Data/CSV/core/Teams.csv)
- [Recent Teams CSV](https://github.com/AcroTaken/Baseball-Stats/blob/main/data/Teams.csv)

## Important limitation

The dataset contains only one champion per season. The project therefore uses balanced accuracy, precision, recall, F1, ROC-AUC, and precision-recall AUC rather than relying on ordinary accuracy. It is an educational analysis and should not be used for betting or financial decisions.
